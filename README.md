# AI클럽 (AI Club)

AI클럽은 인공지능 커뮤니티로써 2017년 모임을 시작으로 매년 주요 기술들을 함께 모여서 연구하고 공개하는 모임입니다.

## 2026년 연구 주제

2026년에는 다음 세 가지 주제를 중심으로 연구하며 성과를 공유하고자 합니다:

- **피지컬 AI (Physical AI)**: 물리적 세계와 상호작용하는 인공지능 시스템 연구
- **생성 AI 콘텐츠 제작 (Generative AI Content Creation)**: 생성형 AI를 활용한 다양한 콘텐츠 제작 기술 연구
- **AI 에이전틱 (AI Agentic)**: 자율적으로 작동하는 AI 에이전트 시스템 연구

## 프로젝트 공유

이 저장소는 AI클럽 2026년도 연구회 프로젝트의 오픈소스 공유 공간입니다.
